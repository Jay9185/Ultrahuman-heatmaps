# Ultrahuman Ring Air × Flight Training: Interactive Charts

Interactive charts from a 168-day, N=1 self-experiment: Ultrahuman Ring Air sleep, HRV and recovery data cross-referenced against 47 flight training days in a Piper PA-28 at Phoenix Deer Valley (KDVT).

- `fig1_workload_recovery.html`: flight workload vs next-day recovery
- `fig3_recovery_heatmap.html`: recovery score heatmap
- `fig4_landings_recovery.html`: landing count vs recovery

> 📖 **Read the analysis:** the full write-up, methodology and caveats are on TurbulenceGains: **[Ultrahuman Ring Air Review for Pilots: 168 Days of Sleep, HRV & Fatigue Data](https://turbulencegains.com/imsafe-ultrahuman-ring-pilot/)**. The TRMNL dashboard that displays this data lives in [TRMNL-ULTRAHUMAN](https://github.com/Jay9185/TRMNL-ULTRAHUMAN).

This is a personal dataset, not a clinical study or fitness-for-duty tool.
